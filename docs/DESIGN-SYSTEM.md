# Design system foundation

Brand primitives: yellow `#FFDF1B`, black `#000000`, white `#FFFFFF`. Prefer Segoe UI and semantic resource tokens. Use visible keyboard focus, clear status labels, and accessible contrast. Keep presentation changes separate from business state.

The current native app only includes a small Light theme resource dictionary. The complete design system, dark theme, component states and accessibility review are not yet implemented or validated in WinUI.
